02 · LAWS

输入关键词过滤（窄网关：只返回匹配行，不铺全量）。每条法则 = 一扇门，交互只交换最小必要信息。

一

结论前置

标题下 5 秒内出现一句可行动的结论（TL;DR），证据按需下钻。人不该读完报告才知道结论。

ia · 结论
二

窄网关，不搬运

搜索只返回匹配行、聚焦只传一个 pane_id、勾选只回传增量。绝不全量铺开。

ia · 窄网关
三

交互是接口，不是装饰

瘦身可以砍内容，绝不砍交互。搜索/排序/聚焦/勾选/复制是窄网关本身——最常见的翻车点。

interact · 交互
四

行动闭环

诊断必须带「行动」：可勾选、有进度、可一键复制为 Markdown，把决策状态反馈回 agent。

interact · 行动
五

诚实可审计

标注采集命令/时间戳/来源；没问题就说没问题，瞬时尖峰标注"非持续"。可复现才值得信任。

trust · 诚实
六

单文件自包含

无 CDN、无构建步骤、离线可用、手机可看。交付物不绑架用户环境。

compose · 单文件
七

会话产物主动归集

从聊天证据归集 main + sub-artifact，不等用户点名"产物在哪"；只收有证据的项目。

compose · 归集
八

组合产物 main + subs

多页产物拆成 main（结论+窄门）与 sub-*.html（自包含），避免 >200KB 单文件 token 爆炸。

compose · 拆分
九

改动预览 = 冻结窄门条 + 定位闪烁

超长单 HTML / SPA 改动时注入默认折叠顶栏：一行结论 + tag 跳转闪烁，评审只看增量。

changes · 预览
十

设计稿 vs WebApp 漂移基准

不数 selector，测语义 Fidelity 4 态（full/partial/gap/overflow）+ 对抗验证；溢出 ≠ 偏离。

trust · 漂移
十一

SVG / 图片 = 内联默认

一律内联进 HTML（<svg> 或 data URI），绝不外链文件；独立文件 ≠ 交付。

compose · 内联
十二

SVG 主动绘制数据与界面

有形状就手写内联 SVG（环形/条/折线/流程/UI mock），别等用户追问"where is the visual SVG?"。禁引 chart.js/d3。

compose · SVG
十三

HITL 人机凭据窄门

密码/API key/验证码/二维码：安全可复制不卡死，零远程端点，页脚声明仅本机使用。

interact · 凭据
十四

视觉密度与布局纪律

对称网格（2×2）、轻量结论条 + 主色左边框、留白三件套。密度是布局第一红线，页面"一眼不慌"。

compose · 密度
