Skill 包导入

适合已有可复用技能、或从外部 / 旧专家导出的场景。上传即回填身份，技能自动成为一名专项员工。

空白创建

适合从零设计专家。保留现有三步向导，不引入任何解析假设。

产品规则

包格式与解析

支持 .zip 与 .skill；必须含根级 SKILL.md，frontmatter 需有 name 与 description。version 缺省为 1.0.0。scripts / references / assets 目录按原样随包入库；__pycache__、node_modules 等排除（对齐 package_skill.py）。

回填与映射

name → 专家名称（必填校验）；description 首行 → 岗位职责；frontmatter 可选 industry → 所属行业。上传技能生成一名专项员工，核心技能即该 Skill 名称，加入第 2 步已选员工。

校验失败处理

非 zip、缺 SKILL.md、frontmatter 缺 name/description 均不进入回填，停留在上传区并给出具体错误。本地即时提示，不上传损坏内容。

安全与边界

沿用现有草稿机制：测试在隔离草稿目录生成 Plugin，每个用例启动全新 Agent SDK。导入不改发布门禁——仍需第 3 步测试通过才可发布。
