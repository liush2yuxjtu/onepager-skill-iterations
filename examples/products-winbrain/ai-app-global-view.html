结论 1 · 选型前端交互用 Vercel AI SDK（useChat 流式 UI），自主 Agent 循环用 Claude Agent SDK（本项目已选后者），两者可混用。
结论 2 · 现状webapp 已具备 Agent SDK 大部分核心能力（MCP/Hooks/权限/沙盒/会话持久化），但缺 6 项：Checkpointing、OTel、结构化输出、Tool Search、子代理、托管部署。
结论 3 · 最快补强① 接 OTel + 成本追踪 ② 结构化输出接入业务 API ③ 评估 Vercel 托管（vercel-functions/sandbox），把 LAN 版变公网版。

安全基线（Sandbox B）

  • OS Sandbox + PreToolUse 路径门禁双保险，fail closed，绝不降级裸跑

  • 会话 10 分钟销毁 / 聊天导出按项目隔离保留 30 天；LAN 仅绑定 RFC1918
