# 能力 UI 改动 改动前 → 改动后 优先级
1Structured output 聊天流内渲染"结构化 JSON 卡片" 纯文本回复 → 校验过的数据卡片（Schema/Zod 徽章 + 可复制 + 可入库 + 可二次编辑） P1 最该早补
2Subagents 活动流升级为"并行子代理卡片"（各自进度条） 单条"正在运行…" → 多路并行进度 + 模型/工具标签 P3
3can_use_tool 危险操作"审批卡片"（允许 / 拒绝 / 改写后执行） 自动拒绝(无反馈) → 人工三选一，AI 可感知结果 公网版前
4Checkpointing AI 结果消息附"回滚到检查点"按钮 + 文件清单 改坏无路可退 → 一键还原回合前状态 P2
5OTel + 成本 右侧栏"成本与观测"面板 + 底部状态栏 trace 计数 看不见 → 会话成本 / tokens / 缓存命中 / traces 实时可见 ✅ 已实现 2026-08-13：ObservabilityLedgerAdapter（本地 JSONL + 标准 OTLP/HTTP exporter）+ /api/v1/observability + 项目页观测卡片（今日/累计成本、Token、回合数、OTLP 状态）
6Todo lists 右侧栏"Todo 清单"（勾选进度）+ 聊天内联进度行 无序活动流 → 结构化待办，长任务可跟踪 ✅ 已实现 2026-08-13：task_started/updated/progress/notification → Todo 账本 + 项目页清单
7Tool Search （未画入线框）输入区 @工具 检索建议 固定白名单 → 检索式扩展 暂缓 by design

设计原则：全部改动只发生在「聊天区消息形态 + 右侧信息栏 + 状态栏」，导航、会话、沙盒与权限架构不变；TUI（Ink）可复用同一套语义（消息类型 + 侧栏组件）。
